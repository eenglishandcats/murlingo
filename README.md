# МУРлинго

[Играть бесплатно](https://eenglishandcats.github.io/murlingo/)

Этот открытый репозиторий содержит инфраструктуру проверенной публикации и зашифрованную копию рабочих исходников. Читаемые исходники и полные учебные задания не публикуются.

`Check and publish Murlingo`: сборка → проверки всех разделов → Chromium и WebKit → публикация GitHub Pages. Ошибка на любом этапе блокирует новую публикацию. Текущая версия игры остаётся доступной. Закрытые диагностические данные также зашифрованы; открытый summary содержит только результаты проверок.

Ручной запуск с `verify_blocking=true` — намеренно неуспешная проверка защитного барьера, без публикации. Секрет `MURLINGO_SOURCE_KEY` необходим; без него полная проверка не может быть заменена на формальный успешный результат.
